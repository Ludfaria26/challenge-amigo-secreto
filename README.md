# 🎁 Challenge do Amigo Secreto

Este projeto é um desafio simples e divertido de **Amigo Secreto** desenvolvido com **HTML, CSS e JavaScript**.

## 🚀 Sobre o projeto

O objetivo do projeto é simular o sorteio de um Amigo Secreto, onde cada participante adiciona seu nome e, ao final, é feito o sorteio de forma aleatória.

> 📌 Projeto elaborado por **Ludmila Faria**, em parceria com a **Alura** e **Oracle Latam**.

## 📂 Estrutura do projeto

* `index.html` → página principal
* `style.css` → estilos da aplicação
* `app.js` → lógica do sorteio e interação com a interface
* `assets/` → imagens e ícones utilizados

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**

## 📦 Como rodar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/usuario/challenge-amigo-secreto.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd challenge-amigo-secreto
   ```

3. Abra o arquivo `index.html` em seu navegador favorito.

## 🎲 Funcionalidades

* Adicionar nomes de participantes
* Listar participantes
* Realizar o sorteio do Amigo Secreto
* Exibir o resultado de forma dinâmica
